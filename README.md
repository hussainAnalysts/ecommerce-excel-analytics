# E-commerce Performance Analytics Dashboard

## Overview

An end-to-end e-commerce analytics project developed in Microsoft Excel
to evaluate traffic, conversion, revenue, marketing performance,
product performance, and customer/device behaviour.

## Business Objective

The analysis was designed to answer key business questions:

- What is the trend in website sessions and order volume?
- What is the session-to-order conversion rate?
- Which marketing channels are most successful?
- How has revenue evolved?
- What is revenue per order and revenue per session?
- Which products and devices drive business performance?

## Tools & Technologies

- Microsoft Excel
- Power Query
- Power Pivot
- DAX
- PivotTables
- Data Visualization
- Conditional Formatting
- Interactive Slicers

## Key KPIs

- Total Orders
- Net Revenue
- Gross Profit
- Website Sessions
- Conversion Rate
- Average Selling Price
- Revenue per Session
- Gross Profit per Order

## Key Insights

- Revenue declined significantly during the first part of the year
  before recovering toward year-end.
- Website traffic recovered strongly, but conversion efficiency did
  not fully return to its early-year peak.
- Google Search was the dominant marketing channel by revenue.
- Desktop generated the majority of revenue.
- Monday recorded the highest order volume.
